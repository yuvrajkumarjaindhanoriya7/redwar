# YJD TerraForge

A modular, original Terraria-inspired 2D browser sandbox/adventure game.

## Run locally
Use a local HTTP server because the game uses JavaScript ES modules.

Example:
`python -m http.server`

Then open `http://localhost:8000/`.

## GitHub Pages
Upload the entire folder to a repository and enable GitHub Pages for the branch/folder containing `index.html`.

## Controls
- A/D: move
- W / Space: jump
- Left mouse: mine
- Right mouse: place selected block
- Mouse wheel: select hotbar slot
- E: inventory
- C: crafting
- Esc: pause

## Modes
- Survival
- Creative

All art is procedurally drawn; no Terraria assets or code are included.
